SciPy is a Python module for scientific and technical computing. It builds on NumPy and provides higher-level routines for common mathematical and engineering tasks.

How SciPy Relates to NumPy

NumPy provides the array foundation and core numerical behaviour. SciPy adds specialised tools on top of that foundation to carry out common scientific calculations, including modules for optimisation, integration, interpolation, and signal processing. Many SciPy functions are able to receive NumPy arrays as input and return NumPy arrays as output, allowing functions to be applied to entire data sets efficiently and conveniently.

Why SciPy Is Widely Used

SciPy gives access to robust implementations of complex algorithms without requiring you to implement them from scratch.

As with NumPy, much of the underlying implementation uses compiled languages such as C, C++, and Fortran, which can provide strong performance compared with pure Python implementations.
